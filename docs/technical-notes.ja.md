## 取得処理と式

`updateKinematics()` は `ACCEL_XOUT_H` からの 14 バイト読み取り長を検査し、加速度・ジャイロ値を取得します。式に用いるのは加速度のみで、16384 LSB/g はライブラリの ±2g 初期設定に対応します。オフセット校正、融合、DMP/FIFO、速度・軌跡再構成はありません。合加速度は重力を含み、エネルギー積分ではありません。動的加速度と取り付け方向が傾斜推定に影響します。

GPIO4/5 のソフトウェア TWI は 400 kHz、クロックストレッチ上限 20000 µs、読み取り引数 20 ms を指定しますが、ハードリアルタイム保証ではありません。失敗時は無効化して 2 s ごとに再初期化します。有限値かつ合加速度 >0.05g を必要とし、全ゼロを正常とは扱いません。

```math
\theta=\mathrm{atan2}(-a_x,\sqrt{a_y^2+a_z^2})\frac{180}{\pi},\quad
\phi=\mathrm{atan2}(a_y,a_z)\frac{180}{\pi}
```

```math
\lVert\mathbf a\rVert=\sqrt{a_x^2+a_y^2+a_z^2},\qquad a_i=\frac{\mathrm{raw}_i}{16384}
```

<a id="feedback"></a>

## 閾値・PWM・周期

`posture_logic.h` の `abs(pitch)>30 || abs(roll)>35` を LED と API が共用し、閾値と等しい値では警告しません。無効時は消灯します。モード変更で PWM を初期化し、強度を 0–1023 に制限、GPIO2 は `1023-intensity` を出力します。通常は 25 ms ごとに ±5 の線形三角波、警告は 50 ms ごとに反転し、理想周期 100 ms（10 Hz）です。通信とループ処理で実周期は変わり、正弦/Gamma 制御、ヒステリシス、継続時間条件はありません。

## 通信とパケット

HTTP ポート 80 は GET `/` と `/api/data` のみです。JSON は `pitch/roll/accel`、`valid`、`abnormal`、両閾値、`age_ms` を含み、無効測定値は `null` です。画面はバックエンドの判定を使い、無効、1000 ms 超、接続失敗で正常表示を解除します。1500 ms で取得を中断し、完了 200 ms 後に再取得するため重複しません。遠隔 LED・閾値変更 API はありません。

TCP は有効値のみ最短 100 ms 間隔で送信し、再接続は 2 s 間隔です。数値 IPv4 で DNS を避け、接続タイムアウトは 50 ms、送信余裕不足時はスキップします。同期・単一スレッドのため、全体の遅延 50 ms を保証しません。標準 Python の `tools/telemetry_receiver.py` は有限値と行長を検査し、旧例程の挨拶に応答します。数値ストリームにはアプリ ACK、時刻、連番がありません。

AP はシリアルの `softAPIP()` を確認し、既定の受信先 `192.168.4.2:8080` が割り当て済みとは仮定しません。ネットワーク設定はサンプルまたはローカルの無視対象ヘッダーに置きますが、過去の Git 履歴から旧設定が消えるわけではありません。

```text
PKT:P=<pitch>,R=<roll>,A=<acceleration_in_g>
```

写真は円形ESP-12Fノード、MPU6050、縫製取り付けを示しますが、銀/ステンレス糸の区別、線径・抵抗率、洗濯耐性、信頼性、量産性は証明しません。導電糸にADC/ブリッジ取得経路はなく、ひずみセンサとしての実装はありません。

編集可能な回路図、PCB工程、BOM、電源測定はありません。部品画像・演習回路は参考資料で、TP4054/SGM2019、800 mAh電池、充電電流、完全な保護、稼働時間を実物の仕様として確定しません。GPIO2はコード上のアクティブLOW LED出力です。外付けLEDと電源は実板で確認します。旧6DOF軌跡や融合の構成図は現行アルゴリズムの根拠にしていません。

演習チームの背景は保持しますが、版が一致しない資料から全設計を個人へ帰属させません。担当、当時の稼働ファームウェア、測定記録は未確認です。
