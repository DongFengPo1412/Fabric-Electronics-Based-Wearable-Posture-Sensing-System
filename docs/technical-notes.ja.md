## 取得と計算式

```math
\theta=\mathrm{atan2}(-a_x,\sqrt{a_y^2+a_z^2})\frac{180}{\pi},\quad
\phi=\mathrm{atan2}(a_y,a_z)\frac{180}{\pi}
```

```math
\lVert\mathbf a\rVert=\sqrt{a_x^2+a_y^2+a_z^2},\qquad a_i=\frac{\mathrm{raw}_i}{16384}
```

`updateKinematics()` は `getMotion6()` で6個の `int16_t` を読み、加速度を16384で除算します。今回のMPU6050 1.4.5ライブラリは既定で±2g・±250°/sに初期化しますが、スケッチはオフセットを明示校正していません。`atan2` の値を度へ換算し、合成加速度には重力が残ります。運動エネルギー積分ではありません。

`raw_gx/raw_gy/raw_gz`、積分時間、融合状態は使用しません。DMP/FIFO取得、ヨー、速度・位置再構成、運動時の警告抑制もありません。準静的仮定、装着方向、バイアス、動的加速度が傾斜角へ影響します。センサ分解能や小数表示をシステム角度精度とみなせません。

`Wire.begin(4,5)` と `Wire.setClock(400000)` は設定値です。ESP8266 coreの `Wire` はソフトウェアTWIを使い、独立したハードウェアI2C制御器ではありません。波形は未測定です。IMU自己診断失敗時は警告を出すだけで、コメントの再初期化リトライや有効データ判定はありません。

## 判定・PWM・時間

| 経路 | 実際の条件・間隔 |
| --- | --- |
| ファームウェアLED | `abs(pitch) > 30` のみ。rollは未使用 |
| ブラウザ表示 | `abs(pitch) > 30` または `abs(roll) > 35` |
| PWM更新 | 25 msごとに確認。通常±5、端点は約5/1020。出力は `1023-pwm_val` |
| 警告点滅 | 更新ごとに0/1023を交互出力。理想条件で約20 Hz、コメントの10 Hzではない |
| TCP | 100 ms間隔確認で公称最大約10送信/s。接続やHTTP処理で遅延しうる |
| ブラウザ/主ループ | 200 msタイマー、主ループには `delay(10)`。固定100 Hz取得ではない |

通常の調光は線形三角波で、端点からの周期計算は約10.15 sです。3秒の正弦波・Gamma2.2・ウェーバー則制御ではありません。モード切替時にPWMをリセット・完全制限しないため端点を超える可能性があります。ヒステリシス、継続時間、運動状態による抑制もなく、側傾ではブラウザだけが警告する場合があります。今回これらのコードは変更していません。

## ネットワーク・ページ・形式

`setup()` はAP+STA、HTTP80を設定し、GET `/` と GET `/api/data` のみ登録します。JSONは `pitch`、`roll`、`accel`。送信は小数2桁、表示は角度1桁・合成加速度2桁です。遠隔LED切替、しきい値設定、クラウド、アプリ制御のルートはありません。

`streamTelemetry()` はブロッキング式 `WiFiClient.connect` で設定先 `192.168.4.2:8080` へ再接続し、下記の改行終端テキストを送ります。受信プログラムはなく、アプリ層ACK、時刻、連番、受信結果の反映もありません。

```text
PKT:P=<pitch>,R=<roll>,A=<acceleration_in_g>

```

既定APゲートウェイは通常 `192.168.4.1` ですが、シリアルの `softAPIP()` 出力を確認します。旧画像の `192.168.147.81` はこのAPの固定アドレスではありません。統合版の115200シリアルは初期化ログのみで、毎フレームの3軸出力はありません。接続失敗の反復は単一スレッドの全処理を遅らせる可能性があります。認証情報は利用環境に合わせ、STAパスワードは文書へ再掲していません。

## ハードウェア資料と未確認事項

![過去のノード近景](images/demo_sensing_node.jpg)

![過去の衣服ノード動作画面](images/demo_wearable_dual_node_active.png)

写真は円形ESP-12Fノード、MPU6050、縫製取り付けを示しますが、銀/ステンレス糸の区別、線径・抵抗率、洗濯耐性、信頼性、量産性は証明しません。導電糸にADC/ブリッジ取得経路はなく、ひずみセンサとしての実装はありません。

編集可能な回路図、PCB工程、BOM、電源測定はありません。部品画像・演習回路は参考資料で、TP4054/SGM2019、800 mAh電池、充電電流、完全な保護、稼働時間を実物の仕様として確定しません。GPIO2はコード上のアクティブLOW LED出力です。外付けLEDと電源は実板で確認します。旧6DOF軌跡や融合の構成図は現行アルゴリズムの根拠にしていません。

演習チームの背景は保持しますが、版が一致しない資料から全設計を個人へ帰属させません。担当、当時の稼働ファームウェア、測定記録は未確認です。
